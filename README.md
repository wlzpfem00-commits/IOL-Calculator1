# IOL Calculator — 서버 연결 프로토타입 v0.2.0

**개발·시험 전용. 의료기기가 아니며 임상 사용 금지. 실제 IOL 도수 및 예상 굴절력 계산을 수행하지 않습니다.**

## 새롭게 작동하는 부분
- Python 표준 라이브러리만 사용하는 HTTP API 서버 (`server/main.py`)
- `GET /api/v1/health` : 서버 연결 확인
- `GET /api/v1/capabilities` : 6개 공식의 연결 가능 상태 확인
- `POST /api/v1/calculate` : 계측값 검사 후 **공식별 미연결 상태** 반환
- 공통 웹 화면에서 API 호출 후 각 공식의 상태를 결과 표에 표시
- 원격 HTTPS API 서버 주소 설정 가능 (설정 탭)
- 계산 요청에 Doctor Name, Patient Name, Patient ID를 전송하지 않음

## 로컬 실행 (Windows / macOS)
1. Python 3.9 이상 설치 (추가 파이썬 패키지는 필요하지 않음).
2. 압축 해제 후 프로젝트 최상위 폴더에서 터미널을 엽니다.
3. 다음 명령 실행:

```sh
python server/main.py
```

4. 브라우저에서 `http://127.0.0.1:8000` 접속.
5. **설정 → 서버 연결 확인**을 누르면 `서버 연결 성공`이 표시됩니다.
6. 아무 식별정보도 입력하지 않은 테스트 계측값을 넣고 **결과 화면 보기**를 누르면 공식별 `미연결` 상태가 표시됩니다.

기본 서버는 로컬 PC에서만 접근할 수 있습니다. 종료하려면 실행한 터미널에서 Ctrl+C를 누릅니다.

## 스마트폰 및 PC 앱과 연결
- 웹: 웹사이트와 API를 같은 HTTPS 도메인으로 배포하는 방식 권장. 기본 서버 주소 입력란은 비워둡니다.
- Windows Electron 앱: 앱 **설정**에서 서버 주소(`https://...`)를 입력하고 연결 확인을 누릅니다. `file://` 환경에서는 서버 주소를 반드시 설정해야 합니다.
- Android/iOS Capacitor 앱: 앱 **설정**에서 서버 주소(`https://...`)를 입력하고 연결 확인을 누릅니다. iOS 빌드에는 macOS + Xcode가 필요합니다.
- 이 압축 파일은 네이티브 앱 설치 파일이 아닌 **앱 빌드용 소스코드**를 포함합니다.
- 앱 내 계산 엔진 주소 변경은 현재 기기에만 저장됩니다. 서버 계산식 업데이트를 중앙에서 배포하기 용이한 구조입니다.

## 서버 배포 시 반드시 처리할 사항
**현재 코드 그대로 인터넷에 공개하여 환자 데이터를 처리하지 마세요.** 서버는 연결 검증을 위한 최소 예시로, 사용자 로그인, 권한 관리, 서비스별 인증, 접근 감사 로그, 침입 방어, 운영 모니터링 및 의료정보 저장소가 없습니다.

운영 개발 단계에 필요한 것:
1. 인증된 호스팅/VPS 또는 병원 내부 서버 확보, 고정 도메인 준비.
2. HTTPS/TLS 종단 (예: 리버스 프록시), 외부에는 HTTPS만 허용.
3. 사용자 인증·권한 분리, 데이터 최소 수집, 접근 기록·보존 정책 및 병원 보안 정책 적용.
4. API 서버 프로세스 관리, 백업, 오류 모니터링, 버전 롤백.
5. HTTPS 웹 도메인과 앱 Origins를 운영 상황에 따라 제한하고 CORS 구성.
6. 환자 정보 저장 기능은 별도 설계(현재는 브라우저 localStorage를 쓰므로 실환자 데이터 입력/저장 금지).
7. 공식 라이선스, 렌즈 모델과 상수 출처, 검증용 골든 테스트 세트, 임상의 검증, 의료기기 규제와 변경관리 계획 수립.

`IOL_HOST=0.0.0.0` 설정은 테스트 네트워크 접속을 열지만, **보안 통제 없는 공용 인터넷 노출은 절대 피해야 합니다.**

## API 요청 예시
```json
{
  "apiVersion": "v1",
  "formulas": ["SRK/T", "Hoffer Q"],
  "eyes": {"od": {"al": 23.85, "k1": 43.25, "k2": 44.0, "acd": 3.15, "targetRefraction": -0.25}},
  "constant": {"type": "Personal Constant", "aConstant": 118.4}
}
```

반환값은 `clinicalReady:false`이고, 각 공식의 `iolPower` 및 `predictedRefraction`은 `null`입니다. **임의의 IOL 도수를 산출하지 않습니다.**

## 업데이트 위치
- `server/main.py` : 계산 API 및 입력값 검사 (실제 검증된 계산 모듈 연결은 추후 작업)
- `www/api-client.js` : 웹/앱에서 서버로 전송할 내용
- `www/config.js` : 화면상 공식 목록/입력 범위
- `www/app.js` : 입력 폼, 결과 및 서버 연결 버튼
- `www/index.html`, `www/styles.css` : UI
- `www/service-worker.js` : 서비스워커 캐시 버전 관리

서버 버전과 앱 버전의 호환성을 `apiVersion`으로 관리할 수 있도록 틀을 만들었습니다. **실제로 공식 엔진이 검증되기 전에는 서버가 추천 도수를 반환하지 않도록 유지해야 합니다.**
